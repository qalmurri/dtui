# tuicli v0.1.3

- baris pertama menampilkan mode dan status; baris kedua menampilkan workspace
- menambahkan waktu sistem di sisi kanan baris pertama
- menambahkan opsi `desktop.time_format` menggunakan kode format `strftime`; jika kosong atau tidak diatur, waktu ditampilkan sebagai Unix timestamp dalam detik
- mengatur keybinding melalui bagian `[keybindings]` di `config.toml`; shortcut yang tidak dioverride memakai default bawaan tuicli
- menghapus dukungan scripting Lua dan dependency `mlua`
