# tuicli v0.1.3

- baris pertama menampilkan mode dan status; baris kedua menampilkan workspace
- menambahkan waktu sistem di sisi kanan baris pertama
- menambahkan opsi `desktop.time_format` menggunakan kode format `strftime`; jika kosong atau tidak diatur, waktu ditampilkan sebagai Unix timestamp dalam detik
- mengatur keybinding melalui bagian `[keybindings]` di `config.toml`; shortcut yang tidak dioverride memakai default bawaan tuicli
- membuat tombol ganti mode dapat dikonfigurasi melalui `toggle_mode` (default `f2`)
- mengulang aksi gerak dan resize saat tombol ditahan
- menyesuaikan ukuran area desktop dan PTY dengan dua baris header, serta hanya me-resize PTY yang berubah
- menghapus scaffold panel dan registry aplikasi yang belum digunakan
- menghapus dukungan scripting Lua dan dependency `mlua`
- mensyaratkan input dan output terminal interaktif, dengan pesan yang jelas saat dijalankan melalui pipe/redirect
- menormalkan modifier keyboard dan mendukung kombinasi modifier serta nama tombol umum pada `config.toml`
- memakai profil PTY xterm 256 warna tanpa mengiklankan truecolor yang belum tentu tersedia di TTY luar
- menyimpan state sesi di direktori state XDG; `session.toml` di direktori konfigurasi tidak dibaca
