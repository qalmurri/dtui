# tuicli v0.1.4

- merapikan `DesktopConfig::default` agar mengikuti hasil Clippy
- menyiapkan PKGBUILD dan `.SRCINFO` untuk membangun paket Arch Linux dari source v0.1.3
- menyiapkan formula Homebrew khusus Linux untuk source v0.1.3
- menambahkan Nix flake untuk `x86_64-linux` dan `aarch64-linux`
- menambahkan dokumentasi status distribusi paket tambahan; submission AUR dan Homebrew belum dipublikasikan
- mengembalikan TTY dan menutup sesi PTY secara normal saat menerima SIGINT, SIGTERM, atau SIGHUP
- mengurangi render ulang saat idle dan menghapus alokasi string per sel terminal
- mengompilasi keybinding sekali saat startup, membatasi interval polling runtime, dan membatasi state sesi dengan ID yang tidak dapat dilanjutkan
- menonaktifkan scrollback PTY yang belum ditampilkan UI dan menangani kegagalan input PTY per sesi
- menolak peluncuran `tuicli` dari shell PTY yang dikelola `tuicli` agar instance tidak bersarang
- menampilkan rata-rata frekuensi CPU dalam GHz di sisi kiri jam pada status bar
